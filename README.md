# ZapretCloud 2.0

Программа для обхода блокировок на основе zapret (winws / winws2). Самостоятельная: движок zapret
(winws, WinDivert, списки, lua, пресеты) встроен в папку `engine`.

## Запуск из исходников
`run.bat` (нужен Python 3.11+ с галочкой «Add python.exe to PATH»).

## Сборка программы и установщика
1. Установите **Python 3.11+** (python.org, отметить «Add python.exe to PATH»).
2. Установите **Inno Setup 6**: https://jrsoftware.org/isdl.php (при установке оставьте всё по умолчанию,
   русский язык входит в комплект).
3. Добавьте папку проекта в исключения антивируса (WinDivert часто даёт ложные срабатывания).
4. Запустите **build.bat**. Он:
   - ставит зависимости и PyInstaller;
   - собирает программу в `dist\ZapretCloud\` (ZapretCloud.exe + движок в `engine\`);
   - собирает установщик `installer\Output\ZapretCloud_Setup_2.2.14.exe`.
5. Готовый установщик можно запускать и раздавать — Python для него не нужен.

Если Inno Setup не установлен, build.bat всё равно соберёт программу в `dist\ZapretCloud` (портативная версия;
чтобы данные хранились рядом с exe, а не в %AppData%, положите рядом пустой файл `portable.txt`).

## Где что хранится
- Программа: `C:\Program Files\ZapretCloud` (движок — в `engine\`).
- Данные пользователя: `%AppData%\ZapretCloud` — настройки, свои пресеты (`presets\`), свои сайты (`sites.json`),
  результаты тестов, логи. Не удаляются при обновлении; при удалении программы спрашивается, удалить ли их.
- Данные старой Zapret Studio переносятся автоматически при первом запуске (или вручную: Настройки → Профиль).

## Возможности 2.0
- **Свои сайты** для каждого пресета (Главная → «Свои сайты»): добавление списком, удаление, поиск, выбор блока
  стратегии, необязательное добавление IP (ipset) через DoH. Файл пресета не изменяется — сайты подставляются
  отдельным блоком при запуске.
- **Профиль**: Настройки → Профиль — сохранить всё в один файл `.zcprofile`, загрузить, сохранить только настройки (`.json`).

## Новое в 2.1
- **Обновление движка** (Настройки → «Обновления движка»): winws2 + lua из bol-van/zapret2, winws из bol-van/zapret, списки сайтов из Flowseal (только добавление адресов). Автопроверка раз в 24 ч, резервная копия и откат. WinDivert.dll и Monkey64.sys не трогаются.
- **Сторож**: раз в N минут (по умолчанию 5) лёгкими запросами проверяет, что обход работает; если перестал — уведомление и окошко с предложением другого пресета.
- **Проверка сайта**: показывает, почему сайт не открывается (DNS / IP / DPI), и добавляет его в обход одной кнопкой.
- **Проверка конфликтов** при запуске пресета: GoodbyeDPI, другие сборки zapret, службы WinDivert, VPN.
- **Мини-виджет** со статусом и кнопкой вкл/выкл (включается в Настройках или в трее).
- **Мастер первого запуска** (можно перезапустить в Настройках).

## Новое в 2.2 — встроенный VPN
- Отдельная вкладка **VPN**: свой сервер по ссылке `vless://` (VLESS + Reality + Vision и др.), `vpn://` (Amnezia, XRay) или по подписке (с остатком трафика и сроком).
- Ядро — sing-box 1.14 (скачивается один раз при первом включении, ~33 МБ, в `engine\vpn`).
- Режимы: **TUN** (весь трафик ПК) или **системный прокси**.
- Маршрутизация: **умная** (zapret, а сайты, которые не открылись, автоматически переводятся на VPN; раз в 6 ч перепроверяются), **только список**, **всё через VPN** (российские сайты напрямую).
- Готовые наборы сайтов (ИИ-сервисы, Meta/X, стриминг, разработка), свои списки «через VPN» и «всегда напрямую».
- Правила для программ (exe всегда через VPN / напрямую).
- Раздача на телефон: прокси для iPhone/Android в домашней Wi-Fi сети.
- QR-код сервера для Happ / v2RayTun на телефоне.
- «Проверка сайта» → кнопка «Открывать через VPN».
- Мини-виджет показывает zapret / VPN и какие сайты сейчас идут через VPN.
- При TUN программа сама перезапускает winws с `--wf-iface` (только физический интерфейс), на время автоподбора VPN приостанавливается.

## Изменения 2.2.14
- Главная: фильтр пресетов по результату автоподбора у вашего провайдера — «от 50% / 75% / 90% / 100%»; при включённом фильтре лучшие пресеты наверху.
- Автоподбор: таблица результатов показывает только выбранный набор («Только Zapret 2» и т.д.), а не старые результаты всех движков; в строке прогресса виден движок текущего пресета.

## Изменения 2.2.13
- Автообновление программы: проверка последнего релиза на GitHub (`Ra1ncloud/XCloud-services`), уведомление о новой версии, скачивание установщика и тихая установка поверх с автоматическим перезапуском. Настройки → «Проверить обновления» показывает и версию программы.
- Сборка через GitHub Actions: при push тега `vX.Y.Z` собирается установщик и публикуется релиз.

## Изменения 2.2.12
- Движок zapret2 обновлён с v1.0.3 до v1.0.5.2 (winws2.exe, zapret-lib/antidpi/auto.lua): быстрее подбор профиля, исправления сборки TCP-опций, Lua 5.5.1.

## Изменения 2.2.11
- Безопасность VPN: служебные локальные прокси (проверка сайтов, загрузка подписок) теперь с паролем, который генерируется при каждом запуске — посторонние программы на ПК не могут пройти через них и узнать IP сервера.
- В режиме TUN общий локальный прокси (порт 10808) больше не открывается, если не включена раздача в домашнюю сеть.
- При раздаче в домашнюю сеть в режиме TUN программы на самом ПК не могут пользоваться этим прокси (доступ только для других устройств сети).

## Изменения 2.2.10
- VPN (TUN): если в Windows остался «призрачный» адаптер ZapretCloud (ошибка «Cannot create a file when that file already exists / Element not found»), программа автоматически переключается на запасное имя адаптера (ZapretCloud2…4) и запоминает рабочее.

## Изменения 2.2.9
- VPN: если запуск не удался, программа сама делает до 3 попыток с очисткой зависших процессов и TUN-адаптера (как «Починить VPN»).
- Неудачные попытки запуска пишутся в `%APPDATA%\ZapretCloud\vpn\start-errors.log`.

## Изменения 2.2.8

- Кнопка «Поддержать» в правом верхнем углу настроек: окно с QR-кодом и номером кошелька ЮMoney, кнопкой перевода и адресом MetaMask (с QR) для крипты.

## Исправления 2.2.7

- В набор «Работа и разработка (Notion…)» добавлен сервер файлов Notion: вложения и архивы из Notion скачиваются через тот же VPN, что и сам Notion.
- Если запущен сторонний VPN (Happ, Hiddify, v2rayN, Amnezia и т.п.), программа не пытается включить свой VPN и прямо пишет, что мешает. Если сторонний VPN запустили, когда наш уже работал, вместо «VPN неожиданно отключился» показывается, какой именно VPN его выбил.

## Исправления 2.2.6

- Ошибка при запуске программы на последнем шаге установщика: установщик запускал её без прав администратора, а программе они нужны. Теперь запускает с правами, которые уже получил при установке.

## Исправления 2.2.5

- TUN иногда не поднимался (чаще в умном режиме и при переключении режимов): Windows создаёт адаптер 10–30 секунд, а программа ждала только 12 и обрывала запуск. Теперь ждёт до 45 секунд.
- Перед запуском TUN программа дожидается, пока Windows удалит адаптер прошлого запуска.

## Исправления 2.2.4

- Кнопка «Починить VPN» на странице VPN: останавливает VPN, убирает зависшие процессы sing-box и запускает заново.
- Если TUN не поднялся из-за зависшего адаптера, программа сама чистит процессы и пробует ещё раз.
- Колесо мыши над выпадающими списками (режимы TUN/прокси, «Умная» и т.д.) больше не меняет их — страница просто листается. Значение меняется только если открыть список вручную.

## Исправления 2.2.3

- VPN в режиме TUN не поднимался на части ПК («open interface take too much time»): убраны `mtu 9000` и стек `mixed`, теперь стандартный MTU и стек `gvisor`.
- Перед запуском VPN программа дожидается, пока завершатся зависшие процессы sing-box и Windows освободит TUN-адаптер.

## Исправления 2.2.2

- Прямой резолв DNS переведён на системный резолвер: DoH 1.1.1.1 напрямую блокировался провайдером, из-за чего запросы зависали и сайты не открывались.
- TUN-интерфейс работает только по IPv4 (`strategy: ipv4_only`); дублирующие IPv6-запросы убраны.
- Адрес TUN изменён с 172.19.0.1 на 172.29.237.1, чтобы не конфликтовать с другими клиентами на sing-box.

- При включённом VPN (режим TUN) zapret теперь всегда работает только на физическом сетевом адаптере: программа сама проверяет фильтр `--wf-iface` и перезапускает winws, если он не применился. Это устраняет ошибки сертификата (NET::ERR_CERT_COMMON_NAME_INVALID) и порчу соединений.
- Новый набор «Telegram» (домены + официальные IP-диапазоны), включается автоматически — Telegram идёт через VPN даже при подключении по IP.
- Notion добавлен в набор «Работа и разработка».
- «Раздача на телефон»: кнопка «QR для Telegram» — настраивает SOCKS5-прокси прямо в Telegram на iPhone/Android (Telegram на iOS не использует прокси Wi‑Fi).


## Выпуск новой версии (GitHub Actions)
1. Поднять версию в `app/paths.py` (`APP_VERSION`) и `installer/ZapretCloud.iss` (`AppVersion`), добавить раздел «## Изменения X.Y.Z» в README.
2. `git commit -am "2.2.14" && git tag v2.2.14 && git push && git push --tags`
3. GitHub соберёт установщик (вкладка Actions) и опубликует релиз `v2.2.14` — программы у пользователей увидят обновление.
